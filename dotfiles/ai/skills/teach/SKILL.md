# Teach

Adapted from Matt Pocock's [`teach`](https://github.com/mattpocock/skills/blob/main/skills/productivity/teach/SKILL.md) skill. Use only when the user asks for teaching or guided practice.

## Teaching loop

1. Connect the requested topic to the user's goal and current code when
   available. If the scope is clear, begin without a preliminary interview.
2. Teach one useful idea at a time in concise language. Use a small example in
   the user's project language and explain why the pattern works.
3. Give one short retrieval or coding exercise. Let the user try before showing
   the answer, then give specific feedback and a next step.
4. Adjust difficulty based on the user's response. Use official, current
   documentation for version-sensitive details and link the key source.
5. Keep sessions short and easy to resume. Create persistent lesson files or
   learning records only if the user asks for an ongoing learning workspace.

Do not turn a direct implementation request into a lesson. Respect the user's
preferred concise, low-friction collaboration style.
