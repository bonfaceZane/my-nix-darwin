# Grill me

Adapted from Matt Pocock's [`grill-me`](https://github.com/mattpocock/skills/blob/main/skills/productivity/grill-me/SKILL.md) skill. This is a user-invoked interview, not a default step before implementation.

Read [the grilling protocol](../grilling/SKILL.md) and use it to resolve the
plan or design through short, focused question rounds. Do not create a glossary
or ADR; use `grill-with-docs` when the user explicitly wants durable domain or
architecture documentation.

For a clear implementation request, skip the interview and follow the user's
request directly.
