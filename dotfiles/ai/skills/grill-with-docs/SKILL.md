# Grill with docs

Adapted from Matt Pocock's [`grill-with-docs`](https://github.com/mattpocock/skills/blob/main/skills/engineering/grill-with-docs/SKILL.md) skill. This is a user-invoked planning and documentation workflow.

Read [the grilling protocol](../grilling/SKILL.md) and use it to resolve the
plan or design. Use `domain-modeling` for precise terms, invariants, and
durable decisions.

Before editing documentation, check the repository's existing glossary and
ADR conventions. Update those documents only after the relevant decision is
settled; create new documentation only when the user requests it or the
project's established process requires it. Do not implement the plan unless the
user asks.
